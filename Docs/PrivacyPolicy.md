Halaman ini digunakan untuk memberi tahu pengunjung mengenai kebijakan kami dengan pengumpulan, penggunaan, dan pengungkapan Informasi Pribadi jika ada yang memutuskan untuk menggunakan Layanan kami.

Jika Anda memilih untuk menggunakan Layanan kami, maka Anda menyetujui pengumpulan dan penggunaan informasi sehubungan dengan kebijakan ini.

## 1. Pemrosesan Data Lokal
VelaPDF adalah sebuah alat bantu pengolah PDF dan dokumen yang beroperasi **sepenuhnya secara lokal (offline) di perangkat Anda**. Kami menghargai privasi Anda, oleh karena itu:
- **Kami TIDAK mengumpulkan, membaca, mengunggah, atau menyimpan dokumen PDF, gambar, atau file apapun milik Anda ke server kami atau pihak penyedia layanan pihak ketiga mana pun.**
- Seluruh proses konversi (*Image to PDF*), pengeditan, atau manajemen file terjadi di dalam perangkat Android Anda.

## 2. Izin Aplikasi (Permissions) yang Membutuhkan Akses
Untuk dapat beroperasi secara normal (seperti membaca file PDF atau mengonversi gambar menjadi PDF), VelaPDF membutuhkan beberapa izin perangkat, antara lain:

*   **Penyimpanan (Storage) / Kelola Semua File (Manage External Storage) / Baca & Tulis Dokumen:** 
    Akses ini hanya digunakan untuk tujuan membaca antrean gambar/dokumen yang dipilih oleh Anda dan untuk menyimpan file PDF keluaran/hasil pemrosesan kembali ke penyimpanan internal/eksternal Anda.

*   **Kamera (Camera):**
    Akses ini diperlukan ketika Anda menggunakan fitur untuk mengambil atau memindai foto dokumen secara langsung dari dalam aplikasi untuk dikonversi menjadi file PDF. Semua gambar yang ditangkap menggunakan fitur kamera ini akan diolah sepenuhnya secara lokal dan tidak pernah ditransmisikan, diunggah ke internet, ataupun disimpan di server luar.

Akses-akses ini tidak digunakan untuk melacak Anda secara diam-diam maupun mengirimkan file secara diam-diam.

## 3. Data Log dan Kesalahan (Crash Data)
Karena aplikasi ini dibuat tanpa integrasi layanan *tracker* pihak ketiga secara masif saat ini, kami tidak mengambil data log atau metrik di luar apa yang secara otomatis dikumpulkan oleh Google Play Console (seperti laporan *crash* yang dikirimkan secara anonim jika aplikasi mengalami *force close*, dengan tujuan memperbaiki bug).

## 4. Keamanan
Kami menghargai kepercayaan Anda karena menggunakan aplikasi ini. Namun, karena tidak ada metode transmisi atas internet pada aplikasi peramban file yang dapat dijamin aman 100%, sangat disarankan agar Anda tetap waspada dan tidak sembarangan memberikan akses perangkat Anda kepada orang tak dikenal. Seluruh tanggung jawab keamanan dokumen fisik/file pada perangkat berada di tangan Anda (pengguna perangkat).

## 5. Tautan ke Situs Lain
Layanan ini mungkin berisi tautan ke situs lain (misalnya dalam README, Halaman Bantuan). Jika Anda mengklik tautan pihak ketiga, Anda akan diarahkan ke situs itu. Perhatikan bahwa situs eksternal ini tidak dioperasikan oleh kami. Karena itu, kami sangat menyarankan Anda untuk meninjau Kebijakan Privasi dari situs web tersebut.
